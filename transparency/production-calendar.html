How Work Reaches the Calendar

  • Requests go to the site owner, who passes them to the team. Nothing reaches the calendar without the site owner accepting it
  • An accepted request is given dates that fit around the regular reports and any major work, and appears in Coming Up
  • Major work, such as the Local Economic Assessment, takes priority for its set period, so a request accepted then will usually be dated after it
  • This page shows titles, dates and a one-line description only. The detail of each request stays with the site owner
