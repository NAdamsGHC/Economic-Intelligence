Transparency

Document Library Evaluation

Last updated 4 November 2026

The AI team keeps a searchable library of published documents, such as government guidance, strategies and evidence reviews, so it can find the right passage instead of relying on memory. This page reports how well that search works, measured by a fixed test that is re-run after every change.

What the Library Does

  • Whole documents are split into passages and indexed two ways, by the words they contain and by what they mean. A second model then reads the question alongside each candidate passage and puts the best answers first
  • Every passage keeps its document, page, edition and date, so anything the team takes from it can be cited and checked
  • When a newer edition of a document arrives, the older one is marked superseded and drops out of normal searches
  • Figures found in a document are treated as leads only. They are always re-pulled from the official source before they are quoted
  • It holds published documents only, not our own products, and everything runs locally at no cost

The library holds 29 documents (27 current and 2 superseded), split into 3,092 passages.

How the Test Works

The test is a set of 38 questions, each worded differently from the document so that it tests meaning and not just matching words. Questions are added whenever documents are, and the settings are re-tested each time.

  • 29 answerable questions – each has an answer key naming the document and page that answers it. Where the answer is a value, the passage must contain the value itself, so a passage from the right page that has lost the number does not count
  • 2 edition questions – the current edition must be found, and the older edition must be recorded as superseded by it
  • 7 questions the library cannot answer – the right result is a flag saying the library probably does not hold the answer

The answer keys were found by searching the original PDFs directly, not through the library, and were then checked page by page in a separate verification pass. That pass found six wrong or incomplete keys, which were corrected (E-2026-47).

Mean reciprocal rank, which averages how near the top the first correct passage sits (1 means always first), is 0.543. Wrongly telling the team an answer is missing is the more harmful mistake, because it stops the search, so the flag is set to fire only when two separate measures agree.

Score History

Each change to a setting is tested against the previous score, and one that lowers it is reverted. Runs 1 to 5 used the first answer key, before verification corrected it, so their scores are not directly comparable with the later runs. From run 11 the library and the test are larger, so those scores are out of a larger total and are not directly comparable with earlier runs either. Adding documents is not a setting, so a fall it causes is recorded, not reverted.

What the Test Does Not Show

  • It tests whether the right passage is found, not whether a written answer built from it is correct. Answers are checked separately by the verification step before any product ships
  • The settings were chosen using this same set of questions, so the scores are likely to flatter the library a little until new questions confirm them
  • The not-in-library flag rests on seven questions, which is too few to rely on. The team is told to read the passages every time, whatever the flag says
  • Tables are the weakest point. The second model reads flattened tables badly, so passages it marks down but the first-stage search ranked highly are returned as extra results

Errors Found While Building It

Five errors were found and fixed during the build, and all are recorded in the Performance Log (E-2026-46, E-2026-47, E-2026-48, E-2026-49, E-2026-50).

Next Steps

  • Add test questions written by the site owner, which reflect real use better than questions drafted from the documents
  • Re-run the test at every quarterly library review and after every large batch of new documents, and add each run to this page
